LIFE TRADE & 5-TRIAL TASK — OFFLINE BROWSER VERSION

Run
1. Extract the entire LifeTrade_Offline.zip folder.
2. Open index.html in a recent desktop browser (Chrome, Edge, or Firefox).
3. Enter participant details and click Start experiment.
4. Use Space to advance instruction pages and the rest screen.
5. On trials, respond with Left Arrow / L for the left option or Right Arrow / R for the right option.
6. At the end, click Download CSV data. If stopped early with Esc, the collected responses can still be downloaded.

Offline use
The task does not use external scripts, fonts, network services, or remote resources. Keep index.html and the Stimuli folder together. It is designed to run by opening index.html directly as a local file.

Important validation note
This is a browser implementation based on the supplied PsychoPy project, not a validated replacement for PsychoPy. Browser/monitor timing can differ from PsychoPy, especially for reaction-time studies. Validate on the target machines before collecting research data. The adaptive row index is clamped to the valid 0–30 range to prevent an out-of-range condition lookup.

Output
The CSV includes participant/session metadata, task and magnitude block, selected condition row, left/right image names, response key, choice type, and reaction time in milliseconds.
